# Tableau Workshop 5 – Walmart Retail Sales Analysis

## Overview
This workshop uses Tableau to analyze Walmart retail sales data from 2012 to 2015. It focuses on calculated fields, shipping time analysis, geographic visualization, and comparing sales across product categories.

## Visualizations

### 1. Average Shipping Time by State
- Analyzed shipping times across different states.
- Used calculated fields to measure the number of days between ordering and shipping.
- Explored how shipping times varied by state.

### 2. Pie Chart Map
- Created a geographic map to visualize sales across states.
- Used product category to distinguish sales on the map.
- Compared sales across product categories and locations.

## Calculated Fields

### Order ID New
Created a new order identifier using the first letter of the state, the first letter of the region, and the original order ID.

### Sales (w/o Category)
Used Tableau's `EXCLUDE` Level of Detail (LOD) expression to calculate total sales while excluding product category from the level of detail.
